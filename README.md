## About

NEON//ASCII is a real-time cyberpunk ASCII camera that transforms live webcam feeds into futuristic glitch-inspired visuals directly in the browser.

Built with WebGL, Three.js, and real-time rendering techniques, the project creates an immersive terminal-style experience with CRT effects, neon aesthetics, VHS glitches, and animated ASCII rendering.

No AI image generation.  
Everything happens live.

---

## Features

- Real-time webcam ASCII rendering
- Multiple ASCII styles
- Cyberpunk UI/UX
- VHS + CRT glitch effects
- Audio-reactive visuals
- Neon shader aesthetics
- Photo & video capture
- Reel-ready 9:16 experience
- Responsive design
